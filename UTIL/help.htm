Home Location

The first time you run NeoTrace it will ask you to set up your Home Location.

It is necessary to tell NeoTrace your home location so that it can accurately represent your trace start location on the map. Enter in as much information as possible into this dialog. Be sure to include your 2-letter country code.

The 2-letter country code is the same as that used on domain names in your country, such as US, CA, UK etc. A list of 2-letter country codes is provided here.

When you submit the data NeoTrace will query a geographical database for the lat/lon of the entered location. That location information will be indicated on the right side of the dialog and a crosshair will indicate the location on the map. That lat/lon values can be modified directly if necessary.

City location data is not yet available for all countries. If a specific location for your hometown or city is not available a default location for your country (typically the capital) will be returned. If you wish to get a better location right away you can enter it by hand after you look it up through the Location Resources on the NeoWorx website or other means.

If you are in the US please be sure to enter your zip code for an accurate location determination.

City and zip code locations are generally accurate to within a mile or two. This is more than enough accuracy for today's purposes.

 

Map Help

There are help topics which cover different aspects of the map display.  Overview information is given here.  Follow the links for further details.

Zooming and scrolling the Map View

To scroll the map hold down the left mouse button and drag on the map.  The map will move according to how far you moved the mouse.  To zoom click the left mouse button without dragging to zoom in, and click the right mouse button to zoom out.

Understanding the Map View

The Map View is a geographical representation of the trace from your computer to another computer connected to the Internet.  The location of your computer is set with the Home Location dialog, if your computer does not appear in the correct place on the map it is because you have not set your location correctly. 

There are several types of map node icons used to represent nodes on the trace map.  The icon shape indicates the reliability of the location information.  In the case of nodes in the middle portion of the trace they are only placed on the map if an accurate location is known.  The target/end node however may be placed even if verified information is not available.  This means that while nodes in the middle portion of the trace are placed reliably, the end node location may not be.  Obviously dots in the middle of a straight line represent unknown locations and are provided only as indicators of the nodes relative position in the trace and not as the node location.

If a node is indicated with an unknown location and you do know the location we urge you to submit data.  The minimum required accuracy is placing a node within the correct city, the maximum possible accuracy is to within a few feet.  Regardless of the level of accuracy you can provide your information is useful to other NeoTrace users.

In addition to the original World and USA maps provided with the NeoTrace distribution there are more maps available for download.  These additional maps include more detailed versions of the original maps as well as close up maps of other regions of the world.  More maps are added from time to time.

Due to the dependency of the Map View on lookups of geographic data this view is the slowest to provide useful information in the initial stages of a trace.  You may want to view a trace in another mode while the trace is in progress.

KeyBoard Shortcuts

All program functions can be performed with the mouse. For your convenience many functions can also be performed with the keyboard.

F5  Start Trace
Esc  Stop Trace
Ctrl + Enter Complete address with www. - .com and start trace
Ctrl + D Delete current trace
Ctrl + G Go Online (Open NeoTrace Home Page)
Ctrl + N Toggle Ping
Ctrl + O View Option Dialog
Ctrl + P Print
Ctrl + S Save
Ctrl + T Start/Stop Trace
Alt + G Change to Graph View
Alt + L Change to List View
Alt + M Change to Map View
Alt + N Change to Node View
Alt + Left View Previous Trace Tab
Alt + Right View Next Trace Tab
Alt + 1 View Trace Tab 1
Alt + 2  View Trace Tab 2
Alt + 3  View Trace Tab 3
Alt + 4 View Trace Tab 4
Alt + 5 View Trace Tab 5


Additionally when you have a view with a scroll bar, such as the List view or Node view you can scroll the view with the PgUp, PgDN, Home and End keys.
